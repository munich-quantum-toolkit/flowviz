# MQT FlowViz - Interactive Visualization of MQT Predictor Compilations

MQT FlowViz is a native macOS and iPadOS application designed to interactively visualize quantum circuit compilation runs from the [MQT Predictor framework](https://github.com/munich-quantum-toolkit/predictor). It allows for in-depth analysis of the input circuit's evolution throughout the compilation.

## Key Features

MQT FlowViz visualizes JSON traces generated by the MQT Predictor framework into an interactive format. The application uses a split-view layout to organize imported traces and breaks down compilation data into distinct, targeted sections:

- **Compilation Overview:** Reviews the static metadata and aggregated statistics of the run. It displays the target hardware and final metrics (Results), tracks total structural changes like added gates or depth (Deltas), and lists execution statistics like total duration and RL policy (Metas).

- **Compilation Metrics:** Plots circuit properties as they evolve step-by-step. A chart grid tracks parallelism, liveness, entanglement ratio, and the agent's reward. Quality indicators like expected fidelity and success probability are grouped on a shared line chart, allowing users to observe how different metrics correlate.

- **Circuit Evolution & Comparison:** Renders the physical gate layout of the quantum circuit at any timestep using serialized OpenQASM 3.0 strings, making it possible to examine the gate-level transformations performed by specific compiler passes. A side-by-side comparison tool allows you to select two intermediate circuits and pinpoint structural differences.

- **Compilation Pipeline Timeline:** Maps the agent's strategy chronologically. It plots all applied compiler passes on a horizontal axis, showing exactly when and in what sequence specific actions (e.g., routing, synthesis, or gate cancellation) were executed.

- **MDP State Evolution:** Complements the action-oriented pipeline by tracking how the core characteristics of the circuit—whether it is laid out, routed, or synthesized—progress toward completion across a horizontal timeline.

## Getting Started

MQT FlowViz is a native macOS/iPadOS application. To run the app on your device:

1. Clone the repository
2. Open the project in **Xcode**.
3. Select your target device (Mac or iPad) and hit `Cmd + R` to build and run the application.

> [!NOTE]
> FlowViz requires previously exported compilation trace files (`.json`) generated explicitly by the `mqt.predictor` framework to visualize data. Ensure you have exported a valid predictor trace from the Python framework before using the app.
> Refer to the MQT Predictor's [Getting Started](https://github.com/munich-quantum-toolkit/predictor/blob/main/README.md#getting-started) section for more information.

## System Requirements

MQT FlowViz requires the following minimum OS versions:

- **macOS:** version 26.4 (Tahoe) or newer
- **iPadOS:** version 26.4 or newer
- **Xcode:** version 26.6 or newer
